# Gen AI Playground

Personal experiments with generative AI. Each folder is a standalone project with its own dependencies, environment file, and README.

## Projects


| Project                                | Description                                                                                                                               |
| -------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| [Voice Agent](Voice%20Agent/README.md) | Browser voice assistant built on the OpenAI Realtime API — talk to it with your mic, get spoken replies with live captions. React + Vite. |
| [RAG](RAG/README.md)                   | Retrieval-augmented generation over PDFs — embeds documents into Qdrant and answers questions with cited sources. LangChain + Node.js.    |


## Prerequisites

- Node.js 20+ and [pnpm](https://pnpm.io)
- An [OpenAI API key](https://platform.openai.com/api-keys) 
- Docker (RAG only, for the Qdrant vector database)
